# Munish Kumar — Agents that automate · iOS & Android

I build **agents that automate company work** (dev, QA, support, marketing) and ship the same products on **iOS and Android**.

Founding engineer at [ASRAX](https://asrax.in): MCP tool bus, Temporal workflows, and agent deployment — plus Flutter apps on web, Play Store, and iOS.
